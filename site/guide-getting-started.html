Run your first FR Legends broadcast

From nothing to a live timing overlay in OBS, in a handful of steps.

1. Get FRLcast running

You have two ways to run it. The desktop app is the full version: download it from the releases, unzip it anywhere and double-click start.cmd. Nothing needs to be installed. It opens the operator console in your browser at a local address. The hosted path at frlcast.my.id is the lighter option for online leagues, where drivers join with an event code.

2. Set up the event and drivers

On the Race control and Drivers pages, give the event a name and round, choose the session type (practice, qualifying, race or endurance), and add each driver with their race number, name, team colour and, ideally, a photo. Photos make the starting grid and driver intros look their best.

3. Point the timing at the game

FRLcast times laps by watching the in-game minimap. On the Vision / AI page you tell it where the minimap is and where the finish line sits, once per track. There is no machine-learning model to train. If your league uses the game's official timing API, you can enter your key there instead and skip the vision setup. See the timing guide for how this works.

4. Add the overlay to OBS

In OBS, add a single Browser Source pointing at the overlay's all.html address shown on the OBS setup page, at 1920×1080. Every graphic lives inside that one source, so there is nothing else to switch on the OBS side. Arrange the widgets on the Layout page and pick a scene on the Event scenes page (pre-show, grid, practice, qualifying, race, results).

5. Go live

Press Start race when the cars roll, and use the flag buttons for race control. The leaderboard, gaps and flags update on the stream in about a second. At the flag, export the results or post them to your league's Discord.

Tip: hand the drivers the Android app so every flag and penalty reaches their phone. See setting up the driver app.

Menjalankan broadcast FR Legends pertamamu

Dari nol sampai overlay timing langsung di OBS, dalam beberapa langkah.

1. Jalankan FRLcast

Ada dua cara. Desktop app adalah versi lengkap: unduh dari releases, ekstrak di mana saja, klik dua kali start.cmd. Tidak perlu instal apa pun. Ia membuka console operator di browser pada alamat lokal. Jalur hosted di frlcast.my.id adalah opsi ringan untuk liga online, tempat driver bergabung dengan kode event.

2. Siapkan event dan driver

Di halaman Race control dan Drivers, beri nama event dan ronde, pilih tipe sesi (practice, qualifying, race, atau endurance), dan tambahkan tiap driver dengan nomor, nama, warna tim, dan idealnya foto. Foto membuat starting grid dan intro driver tampil maksimal.

3. Arahkan timing ke game

FRLcast menghitung lap dengan mengamati minimap dalam game. Di halaman Vision / AI kamu menandai posisi minimap dan garis finish, sekali per track. Tidak ada model machine learning yang perlu dilatih. Jika ligamu memakai API timing resmi game, masukkan key di sana dan lewati setup vision. Lihat panduan timing.

4. Tambahkan overlay ke OBS

Di OBS, tambahkan satu Browser Source yang mengarah ke alamat overlay all.html (ada di halaman OBS setup), ukuran 1920×1080. Semua grafik ada di dalam satu source itu, jadi tidak ada yang perlu diganti di sisi OBS. Atur widget di halaman Layout dan pilih scene di halaman Event scenes (pre-show, grid, practice, qualifying, race, hasil).

5. Live

Tekan Start race saat mobil berjalan, dan pakai tombol flag untuk race control. Leaderboard, gap, dan flag terupdate di stream dalam ~1 detik. Saat finish, ekspor hasil atau posting ke Discord ligamu.

Tips: berikan driver aplikasi Android agar setiap flag dan penalti sampai ke HP mereka. Lihat setup aplikasi driver.
