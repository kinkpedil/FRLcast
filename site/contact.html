Contact

Questions, bug reports and ideas are welcome.

Who runs FRLcast

FRLcast is made and run by kinkpedil12, for the FR Legends league community.

How to reach us

  • Bug reports and feature requests: open an issue on the project's GitHub page. Include what you were doing, what you expected and what happened, and the version shown in the console sidebar.
  • Questions about using FRLcast: read the guides and the FAQ first; most answers are there. Otherwise, open an issue on GitHub and we will reply there.
  • Data and privacy requests: see the privacy policy. For an event's own records (drivers, results), contact the organiser of that event, who controls that data.

Siapa yang menjalankan FRLcast

FRLcast dibuat dan dijalankan oleh kinkpedil12, untuk komunitas liga FR Legends.

Cara menghubungi kami

  • Laporan bug dan permintaan fitur: buat issue di halaman GitHub proyek. Sertakan apa yang sedang kamu lakukan, apa yang kamu harapkan, apa yang terjadi, dan versi yang tampil di sidebar konsol.
  • Pertanyaan tentang cara memakai FRLcast: baca dulu panduan dan FAQ; sebagian besar jawabannya ada di sana. Kalau tidak ada, buat issue di GitHub dan kami akan membalas di sana.
  • Permintaan terkait data dan privasi: lihat kebijakan privasi. Untuk rekaman sebuah event (pembalap, hasil), hubungi penyelenggara event tersebut, yang mengendalikan data itu.
