Frequently asked questions

Short answers to what league organisers ask most. If yours is not here, see the contact page.

What is FRLcast?

A broadcast and race control system for FR Legends leagues. One console runs the timing, flags, penalties, sessions, rounds and championship, and drives the OBS overlays your viewers see. An Android app puts every flag and decision on the drivers' phones.

Does it cost anything?

No. The website, the desktop app and the driver app are free. The website shows advertising to cover hosting.

Do I need the desktop app or is the website enough?

The website runs an event from a browser tab: race control, the overlays, the driver app connection, the live timing page and the season pages. The free desktop app adds the parts that need a program on your own machine: automatic timing from the game's minimap, the official timing API, a natural spoken commentary voice and judges on your local network. Many leagues start on the website and add the desktop app later. The two can be linked so drivers anywhere still connect.

How accurate is the timing?

With the computer vision path, a lap is timed when a car crosses the line you mark on the minimap, interpolated between frames, so a lap time is not rounded to the frame rate. With the official timing API, times come straight from the game server. You can also run fully manual timing and correct any lap by hand.

Do drivers need to install anything?

Only the Android driver app if you want flags, penalties and team radio on their phones. They type your event code once and sign in with their race number. Nothing is needed to appear on the timing screen.

Can one event code run a whole season?

Yes. A season is made of rounds, each with practice, qualifying and race (or practice and a drift competition), and points are scored into the championship when each race finishes. See running a league season.

Does it support drift events?

Yes: judged qualifying on line, angle and style, tandem brackets with One More Time, an optional battle for third, judges scoring from their phones and drift graphics for the stream. See running a drift event.

How do penalties work?

Stewards issue time penalties, warnings, drive throughs, black flags and disqualifications with a reason. Decisions appear on the broadcast and on the driver's phone. Optional licence points carry penalties across the season. See stewarding and penalties.

Can two people run the console?

One console should run an event at a time, because it holds the authoritative timing. Other people can follow on the live timing page, the control room view, or judge from their phones.

Is this an official FR Legends product?

No. FRLcast is an independent project for the FR Legends community, made by kinkpedil12. It uses the official timing API where a league has access to it.

What data do you keep?

Event data that an organiser enters (drivers, timing, results) and the account details needed to sign in. The privacy policy explains it in full, including cookies and advertising.

Pertanyaan yang sering diajukan

Jawaban singkat untuk pertanyaan yang paling sering diajukan penyelenggara liga. Kalau pertanyaanmu tidak ada di sini, lihat halaman kontak.

Apa itu FRLcast?

Sistem siaran dan race control untuk liga FR Legends. Satu konsol menjalankan timing, bendera, penalti, sesi, ronde, dan championship, sekaligus mengendalikan overlay OBS yang dilihat penonton. Aplikasi Android menampilkan tiap bendera dan keputusan di HP pembalap.

Apakah berbayar?

Tidak. Website, aplikasi desktop, dan aplikasi driver gratis. Website menampilkan iklan untuk menutup biaya hosting.

Perlu aplikasi desktop atau website saja cukup?

Website menjalankan event dari tab browser: race control, overlay, koneksi aplikasi driver, halaman timing langsung, dan halaman musim. Aplikasi desktop gratis menambahkan bagian yang butuh program di mesinmu sendiri: timing otomatis dari minimap game, API timing resmi, suara komentar yang natural, dan juri di jaringan lokal. Banyak liga mulai dari website lalu menambah aplikasi desktop kemudian. Keduanya bisa dihubungkan sehingga pembalap dari mana pun tetap tersambung.

Seberapa akurat timing-nya?

Dengan jalur computer vision, lap dihitung saat mobil melewati garis yang kamu tandai di minimap, diinterpolasi di antara frame, jadi waktu lap tidak dibulatkan ke frame rate. Dengan API timing resmi, waktu datang langsung dari server game. Kamu juga bisa menjalankan timing manual sepenuhnya dan mengoreksi lap mana pun secara manual.

Apakah pembalap perlu memasang sesuatu?

Hanya aplikasi driver Android kalau kamu ingin bendera, penalti, dan radio tim tampil di HP mereka. Mereka mengetik kode event sekali dan masuk dengan nomor balap. Untuk tampil di layar timing tidak perlu apa-apa.

Bisakah satu kode event dipakai satu musim?

Bisa. Musim terdiri dari ronde, masing-masing dengan latihan, kualifikasi, dan balapan (atau latihan dan kompetisi drift), dan poin masuk championship saat tiap balapan selesai. Lihat menjalankan musim liga.

Apakah mendukung event drift?

Ya: kualifikasi yang dinilai per line, angle, dan style, bracket tandem dengan One More Time, battle perebutan juara 3 opsional, juri yang menilai dari HP, dan grafis drift untuk stream. Lihat menjalankan event drift.

Bagaimana cara kerja penalti?

Steward menjatuhkan penalti waktu, peringatan, drive through, bendera hitam, dan diskualifikasi beserta alasannya. Keputusan tampil di siaran dan di HP pembalap. Poin lisensi opsional membawa penalti sepanjang musim. Lihat steward dan penalti.

Bisakah dua orang menjalankan konsol?

Satu event sebaiknya dijalankan satu konsol saja, karena konsol memegang timing yang menjadi acuan. Orang lain bisa mengikuti lewat halaman timing langsung, tampilan ruang kontrol, atau menjadi juri dari HP.

Apakah ini produk resmi FR Legends?

Bukan. FRLcast adalah proyek independen untuk komunitas FR Legends, dibuat oleh kinkpedil12. FRLcast memakai API timing resmi kalau liga punya akses ke sana.

Data apa yang disimpan?

Data event yang dimasukkan penyelenggara (pembalap, timing, hasil) dan detail akun yang dibutuhkan untuk masuk. Kebijakan privasi menjelaskannya lengkap, termasuk cookie dan iklan.
