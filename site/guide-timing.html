How automatic lap timing works

Timing an FR Legends race without a timing loop, an ML model or a spreadsheet.

The idea

FR Legends draws a small minimap with a dot for each car. FRLcast watches that minimap and works out where every car is, then times a lap each time a car crosses the finish line you marked. It runs entirely on your machine, so it works offline and costs nothing to run.

The vision pipeline, in plain terms

  1. Colour lookup. Each car's dot has a colour. A prebuilt colour cube turns every minimap pixel into a driver in a single fast pass, with no neural network to train or run.
  2. Blob tracking. The coloured pixels are grouped into blobs, one per car, and a tracker follows each blob frame to frame. If a dot is briefly hidden, the tracker dead-reckons it forward so the car does not disappear.
  3. Line crossing. When a car crosses the finish line, the exact moment is interpolated between frames, and that becomes a lap. Every lap goes through a debounce so a noisy frame never invents a lap.

From those crossings FRLcast derives lap times, best and last lap, gaps to the leader and to the car ahead, sectors, and the live running order.

Setting it up per track

On the Vision / AI page you draw a box over the minimap and mark the finish line, once for a given track and layout. Register each driver's number and colour so the tracker can tell the cars apart. That is all the calibration a track needs.

The official timing API

The FR Legends developer provides an official timing API for partner broadcasters. If your league has a key, FRLcast can poll it instead of watching the minimap: you enter the key and a room key on the timing card, and the same leaderboard, gaps and sectors follow. Because players are identified by an in-game id that changes every room, FRLcast matches players to your drivers by name at event time, the same way the vision path does.

Manual mode

For a low-spec setup with no camera, manual mode lets the operator set the order and add laps by hand, so a broadcast is always possible even without the vision pipeline.

Cara kerja timing lap otomatis

Menghitung balapan FR Legends tanpa timing loop, model ML, atau spreadsheet.

Idenya

FR Legends menampilkan minimap kecil dengan titik untuk tiap mobil. FRLcast mengamati minimap itu, mengetahui posisi tiap mobil, lalu menghitung lap setiap kali mobil melewati garis finish yang kamu tandai. Semua jalan di komputermu, jadi bekerja offline dan gratis.

Pipeline vision, sederhananya

  1. Lookup warna. Titik tiap mobil punya warna. Sebuah color cube siap-pakai mengubah tiap piksel minimap menjadi driver dalam satu pass cepat, tanpa jaringan saraf yang perlu dilatih.
  2. Tracking blob. Piksel berwarna dikelompokkan jadi blob, satu per mobil, dan tracker mengikuti tiap blob antar-frame. Jika titik sempat tertutup, tracker memperkirakan posisinya agar mobil tidak hilang.
  3. Line crossing. Saat mobil melewati garis finish, momen tepatnya diinterpolasi antar-frame dan menjadi satu lap. Tiap lap melewati debounce agar frame yang berisik tidak mengarang lap.

Dari crossing itu FRLcast menurunkan lap time, best/last lap, gap ke pemimpin dan ke mobil depan, sektor, dan urutan langsung.

Setup per track

Di halaman Vision / AI kamu menggambar kotak di atas minimap dan menandai garis finish, sekali per track dan layout. Daftarkan nomor dan warna tiap driver agar tracker bisa membedakan mobil. Itu saja kalibrasi yang dibutuhkan.

API timing resmi

Developer FR Legends menyediakan API timing resmi untuk partner broadcaster. Jika ligamu punya key, FRLcast bisa polling API itu daripada mengamati minimap: masukkan key dan room key di kartu timing, dan leaderboard, gap, serta sektor yang sama akan mengikuti. Karena pemain diidentifikasi dengan id dalam game yang berubah tiap room, FRLcast mencocokkan pemain ke driver-mu berdasarkan nama saat event, sama seperti jalur vision.

Mode manual

Untuk setup spek rendah tanpa kamera, mode manual memungkinkan operator mengatur urutan dan menambah lap secara manual, jadi broadcast tetap mungkin walau tanpa pipeline vision.
