Visibility

When on, the console flashes the fastest-lap banner for a few seconds each time the record falls, and switches to the Results scene (falling back to the results widget) when the chequered flag drops. In a race it also puts the head-to-head on air when two cars stay within a second of each other for a few seconds, and takes it down once the fight is over (never one you turned on yourself). It only does things you can also do by hand.

Audience poll

Use a preset or type your own options (leave the box empty for every driver). Viewers vote on the public live page; the tally shows on the Audience poll overlay widget, and the winner is saved to the race recap when you close it. Needs the votes table (see Help / migration).

Recommended scene layout

1. Source Window Capture → your Android emulator (this is the gameplay).
2. Source Browser → /overlay/all.html (one source with everything), or add the individual URLs above if you want to fade widgets separately in OBS.
3. In the browser source properties tick Shutdown source when not visible off, and leave Refresh browser when scene becomes active off — the overlay reconnects on its own.
4. Custom CSS field in OBS: leave empty. The pages are already transparent.
5. Keep this operator tab open on a second monitor. Capture and detection run in this tab.

Multi-device setup

Capture node http://localhost:4700/node.html

Open this on the machine that shows the game. It runs capture and detection and nothing else, and shares a preview so you can still draw regions from the operator panel on another device. Everything else — race control, drivers, overlays, layout — is done from this panel over the network.

Remote lap trigger

Any device on your LAN can fire a lap with a plain GET request — handy for a phone or a Stream Deck:
http://HOST:4700/api/lap/<driverId>
Driver IDs are listed on the Drivers page.

Keyboard shortcuts

Bind any control to a key. A Stream Deck's Hotkey action sends the same keystroke to this tab — so set a Stream Deck button to the key you pick here, no plugin needed. Click Set, then press the key (or key combo).

OBS control (WebSocket)

Let the console drive OBS: cut cameras on a flag, and save a replay-buffer clip on a marker. Enable the WebSocket server in OBS (Tools → WebSocket Server Settings) and paste the address + password. Keep the address on localhost — a LAN address is blocked from the hosted console.
