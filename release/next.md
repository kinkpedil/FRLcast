## en

- **The console tells you when an update is out**, shows what changed in your language, and updates itself with one click. Your event data, API key, voices and logo are kept, and `data` is backed up first. It refuses while a race is running.
- **The version is shown everywhere**: in the console sidebar, the server window title and the Help page, so a bug report always says which version it came from.
- **Beta channel**: tick "Tell me about beta versions" on the Help page to try new features before race day. Betas never replace the normal download.
- **Readable release notes** in English and Indonesian, and a new changelog page at [frlcast.my.id/changelog](https://frlcast.my.id/changelog).
- Releases are now built by GitHub Actions, so a new version no longer depends on one PC.

## id

- **Console memberi tahu saat ada update**, menampilkan apa saja yang berubah dalam bahasamu, dan bisa update sendiri dengan satu klik. Data event, API key, voice, dan logo tetap aman, dan folder `data` di-backup dulu. Update ditolak selama race berjalan.
- **Nomor versi tampil di mana-mana**: di sidebar console, judul jendela server, dan halaman Help, jadi setiap laporan bug langsung ketahuan versinya.
- **Jalur beta**: centang "Beri tahu saya soal versi beta" di halaman Help untuk mencoba fitur baru sebelum hari race. Versi beta tidak pernah menggantikan download biasa.
- **Catatan rilis yang mudah dibaca** dalam bahasa Inggris dan Indonesia, plus halaman changelog baru di [frlcast.my.id/changelog](https://frlcast.my.id/changelog).
- Rilis sekarang dibuat oleh GitHub Actions, jadi versi baru tidak lagi bergantung pada satu PC.
