## en

- **Sessions reset properly with the timing API live.** Switching from practice to qualifying or to the race, pressing Reset, or pressing Start now starts the board from zero: laps from the earlier session no longer carry over, and best laps are the ones set in this session.
- **New -Lap button** next to +Lap on the live classification. Use it when a car got an extra lap, for example by crossing the line just before the real start. Its order, gaps and best lap follow immediately.
- **+Lap works again with the timing API live** (button and Q W E R T Y U I hotkeys): it corrects that car's lap count instead of being overwritten by the next update.

## id

- **Sesi bisa di-reset dengan benar saat timing API aktif.** Pindah dari practice ke qualy atau ke race, menekan Reset, atau menekan Start sekarang memulai papan dari nol: lap dari sesi sebelumnya tidak terbawa lagi, dan best lap adalah yang dibuat di sesi ini.
- **Tombol -Lap baru** di sebelah +Lap pada klasemen langsung. Pakai saat ada mobil yang dapat lap berlebih, misalnya karena melewati garis sesaat sebelum start sungguhan. Urutan, gap, dan best lap-nya langsung ikut benar.
- **+Lap berfungsi lagi saat timing API aktif** (tombol dan hotkey Q W E R T Y U I): sekarang mengoreksi jumlah lap mobil itu, tidak lagi tertimpa oleh update berikutnya.
