## en
- Rounds: one event code now runs a whole season. Each round keeps its own practice, qualifying and race, and finishing the race scores the round in the championship automatically, with the fastest-lap and pole bonuses. Use the round menu on Race control to start a new round or go back to an earlier one.

## id
- Ronde: satu kode event kini bisa untuk satu musim penuh. Tiap ronde menyimpan latihan, kualifikasi, dan balapannya sendiri, dan begitu balapan diselesaikan poin ronde itu langsung masuk championship, lengkap dengan bonus lap tercepat dan pole. Pakai menu ronde di Race control untuk mulai ronde baru atau kembali ke ronde sebelumnya.
