## en

- **Create your online event without leaving the desktop app.** On the Drivers page ("Drivers from anywhere"), type an event name and the code drivers will use, then press Create and link. No trip to the website dashboard needed.
- The Race page now points you there: "Online league, drivers at home? Set up the online link".
- The sign-in box links to the website for a first-time account.

## id

- **Buat event online tanpa keluar dari aplikasi desktop.** Di halaman Pembalap ("Pembalap dari mana saja"), ketik nama event dan kode yang akan dipakai pembalap, lalu tekan Buat dan hubungkan. Tidak perlu lagi ke dashboard website.
- Halaman Race sekarang menunjukkan jalannya: "Liga online, pembalap di rumah? Atur link online".
- Kotak login punya tautan ke website untuk membuat akun pertama kali.
