## en
- Sessions: run the night as Practice, Qualifying and Race. Start each one, finish it and move on; a finished session is saved with every lap time, best, last and previous lap, lap count, gap and its penalties. Open any session from the Sessions card to see each driver's laps or export it as CSV.
- Penalties now belong to the session they were given in, so a practice penalty no longer adds time to the race.

## id
- Sesi: jalankan malam balapan sebagai Latihan, Kualifikasi, dan Balapan. Mulai, selesaikan, lalu lanjut; sesi yang selesai tersimpan dengan semua waktu lap, lap terbaik, terakhir dan sebelumnya, jumlah lap, selisih, serta penaltinya. Buka sesi mana pun dari kartu Sessions untuk melihat lap tiap pembalap atau ekspor ke CSV.
- Penalti kini terikat pada sesi tempat diberikan, jadi penalti latihan tidak lagi menambah waktu di balapan.
